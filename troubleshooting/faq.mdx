---
title: "FAQ"
description: "Answers to common Acumatica customization questions."
---

<AccordionGroup>
  <Accordion title="Should I modify base application files?">No. Use supported customization and extension mechanisms so changes remain traceable and upgradeable.</Accordion>
  <Accordion title="When should I create a custom table?">Create one when the data has its own identity and lifecycle. Extend an existing DAC when the fields belong to an existing record.</Accordion>
  <Accordion title="Why test with a non-administrator role?">Administrator access can hide missing role rights and navigation configuration.</Accordion>
  <Accordion title="Can I publish directly to production?">Use a staging environment first. Back up production and publish during an approved maintenance window.</Accordion>
</AccordionGroup>
