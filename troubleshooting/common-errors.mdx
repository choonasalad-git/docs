---
title: "Common errors"
description: "Resolve frequent Acumatica customization and publishing failures."
---

<AccordionGroup>
  <Accordion title="A DAC field does not appear">Confirm the extension is active, the control uses the correct data member, and a persistent field has a matching database column.</Accordion>
  <Accordion title="A project fails to publish">Read the first compiler or validation error, verify the target build, and check project dependencies.</Accordion>
  <Accordion title="A screen is missing from navigation">Confirm the sitemap or workspace entry, access rights, and publication status.</Accordion>
  <Accordion title="Changes appear stale">Start a new session and clear application caches using the procedure approved for your environment.</Accordion>
</AccordionGroup>
