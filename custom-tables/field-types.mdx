Every field in a DAC is annotated with one or more attributes that tell the platform how to map the field to the database, how to validate its value, and how to render it on screen. The most important of these is the *type attribute* — the `PXDB*` or `PX*` attribute that determines the underlying SQL data type and whether the field is persisted at all. This page covers every supported type attribute in detail so you can choose the right one for each column in your custom table.

<Tip>
If a field's value is always derived at runtime — for example, a running total computed from child rows, a display-only concatenation of other fields, or a transient flag used only during screen processing — use an **unbound** (`PX*`) attribute instead of a DB-mapped (`PXDB*`) one. Unbound fields never produce a database column, so they add no migration overhead and cannot be accidentally queried against the database.
</Tip>

## DB-mapped field attributes

Use the following attributes for fields that must be stored in the database. Each `PXDB*` attribute maps to a specific SQL Server data type and generates the corresponding column when you publish your customization.

<Accordion title="PXDBString — variable-length or fixed-length text">

Maps to `NVARCHAR(n)` (Unicode) or `VARCHAR(n)` (non-Unicode) / `NCHAR(n)` / `CHAR(n)` (fixed-length). Use this for any text data: names, codes, descriptions, status flags, and free-form notes.

**Parameters**

| Parameter | Type | Default | Description |
|---|---|---|---|
| `length` (positional) | `int` | Required | Maximum number of characters. Maps to the SQL column length. |
| `IsUnicode` | `bool` | `true` | `true` → `NVARCHAR`/`NCHAR`; `false` → `VARCHAR`/`CHAR`. Set to `false` only for ASCII-only codes. |
| `IsFixed` | `bool` | `false` | `true` → fixed-length `CHAR`/`NCHAR`; `false` → variable-length `VARCHAR`/`NVARCHAR`. Use `true` for single-character status codes. |
| `IsKey` | `bool` | `false` | Marks the field as part of the composite natural key used by the selector and URL routing. |
| `InputMask` | `string` | `null` | An input mask applied in the UI (does not affect the DB column). |

**Example: status code (fixed-length, ASCII)**

```csharp
#region Status
[PXDBString(1, IsFixed = true)]
[PXDefault("O")]
[PXUIField(DisplayName = "Status")]
[PXStringList(new[] { "O", "H", "C" }, new[] { "Open", "On Hold", "Closed" })]
public virtual string Status { get; set; }
public abstract class status : PX.Data.BQL.BqlString.Field<status> { }
#endregion
```

**Example: natural key (variable-length, Unicode)**

```csharp
#region OrderNbr
[PXDBString(15, IsUnicode = true, IsKey = true)]
[PXDefault]
[PXUIField(DisplayName = "Order Nbr.")]
public virtual string OrderNbr { get; set; }
public abstract class orderNbr : PX.Data.BQL.BqlString.Field<orderNbr> { }
#endregion
```

</Accordion>

<Accordion title="PXDBInt — 32-bit integer">

Maps to SQL `INT`. Use for numeric identifiers (foreign keys to standard ERP tables), counts, quantities stored as whole numbers, and any integer value that fits within −2,147,483,648 to 2,147,483,647.

**Parameters**

`PXDBInt` has no required positional parameters. The optional `MinValue` and `MaxValue` named parameters add server-side range validation.

**Example: foreign key to a standard table**

```csharp
#region CustomerID
[PXDBInt]
[PXUIField(DisplayName = "Customer")]
[PXSelector(
    typeof(AR.Customer.bAccountID),
    typeof(AR.Customer.acctCD),
    typeof(AR.Customer.acctName),
    SubstituteKey = typeof(AR.Customer.acctCD),
    DescriptionField = typeof(AR.Customer.acctName))]
public virtual int? CustomerID { get; set; }
public abstract class customerID : PX.Data.BQL.BqlInt.Field<customerID> { }
#endregion
```

**Example: integer counter with validation**

```csharp
#region Quantity
[PXDBInt(MinValue = 1)]
[PXDefault(1)]
[PXUIField(DisplayName = "Quantity")]
public virtual int? Quantity { get; set; }
public abstract class quantity : PX.Data.BQL.BqlInt.Field<quantity> { }
#endregion
```

</Accordion>

<Accordion title="PXDBShort — 16-bit integer">

Maps to SQL `SMALLINT` (−32,768 to 32,767). Use when you need an integer but the value range is small and column storage matters — for example, a sort order, a priority level (1–100), or an age in years.

```csharp
#region SortOrder
[PXDBShort]
[PXDefault((short)0)]
[PXUIField(DisplayName = "Sort Order")]
public virtual short? SortOrder { get; set; }
public abstract class sortOrder : PX.Data.BQL.BqlShort.Field<sortOrder> { }
#endregion
```

</Accordion>

<Accordion title="PXDBLong — 64-bit integer">

Maps to SQL `BIGINT`. Use when the value can exceed the `INT` range — for example, external system IDs, bitmask flags covering more than 32 options, or file sizes in bytes.

```csharp
#region ExternalID
[PXDBLong]
[PXUIField(DisplayName = "External ID")]
public virtual long? ExternalID { get; set; }
public abstract class externalID : PX.Data.BQL.BqlLong.Field<externalID> { }
#endregion
```

</Accordion>

<Accordion title="PXDBDecimal — fixed-point decimal number">

Maps to SQL `DECIMAL(28, precision)`. Use for all monetary amounts, rates, percentages, and any value where rounding must be deterministic. Never use a floating-point type for money.

**Parameters**

| Parameter | Type | Default | Description |
|---|---|---|---|
| `precision` (positional) | `int` | `2` | Number of decimal places. Common values: `2` (currency), `4` (unit cost/rate), `6` (exchange rate). |
| `MinValue` | `double` | none | Minimum allowed value (server-side validation). |
| `MaxValue` | `double` | none | Maximum allowed value. |

**Example: currency amount**

```csharp
#region TotalAmount
[PXDBDecimal(2)]
[PXDefault(TypeCode.Decimal, "0.00")]
[PXUIField(DisplayName = "Total Amount")]
public virtual decimal? TotalAmount { get; set; }
public abstract class totalAmount : PX.Data.BQL.BqlDecimal.Field<totalAmount> { }
#endregion
```

**Example: unit cost with higher precision**

```csharp
#region UnitCost
[PXDBDecimal(4)]
[PXDefault(TypeCode.Decimal, "0.0000")]
[PXUIField(DisplayName = "Unit Cost")]
public virtual decimal? UnitCost { get; set; }
public abstract class unitCost : PX.Data.BQL.BqlDecimal.Field<unitCost> { }
#endregion
```

</Accordion>

<Accordion title="PXDBBool — boolean flag">

Maps to SQL `BIT` (`0` = false, `1` = true). Use for on/off toggles, approval flags, and any binary state.

```csharp
#region IsActive
[PXDBBool]
[PXDefault(true)]
[PXUIField(DisplayName = "Active")]
public virtual bool? IsActive { get; set; }
public abstract class isActive : PX.Data.BQL.BqlBool.Field<isActive> { }
#endregion
```

```csharp
#region RequiresApproval
[PXDBBool]
[PXDefault(false)]
[PXUIField(DisplayName = "Requires Approval")]
public virtual bool? RequiresApproval { get; set; }
public abstract class requiresApproval : PX.Data.BQL.BqlBool.Field<requiresApproval> { }
#endregion
```

</Accordion>

<Accordion title="PXDBDate — date without time">

Maps to SQL `DATETIME` but the platform truncates the time portion when reading and writing, treating the value as a date-only. Use for business dates, deadlines, expiry dates, and any date where the time of day is not meaningful.

```csharp
#region DueDate
[PXDBDate]
[PXDefault(typeof(AccessInfo.businessDate))]
[PXUIField(DisplayName = "Due Date")]
public virtual DateTime? DueDate { get; set; }
public abstract class dueDate : PX.Data.BQL.BqlDateTime.Field<dueDate> { }
#endregion
```

For a date that includes a time component, use `PXDBDateAndTime` instead — it preserves the full `DATETIME` value including hours, minutes, and seconds.

</Accordion>

<Accordion title="PXDBGuid — globally unique identifier">

Maps to SQL `UNIQUEIDENTIFIER`. Use when you need a UUID primary key, a reference to a `Users` or `UploadFile` record (the platform uses GUIDs for those entities), or when integrating with an external system that issues GUIDs as object identifiers.

```csharp
#region FileID
[PXDBGuid]
[PXUIField(DisplayName = "Attachment")]
public virtual Guid? FileID { get; set; }
public abstract class fileID : PX.Data.BQL.BqlGuid.Field<fileID> { }
#endregion
```

</Accordion>

<Accordion title="PXDBIdentity — auto-increment primary key">

Maps to SQL `INT IDENTITY(1,1)`. The database assigns the value on insert; you cannot set it manually. Every custom table should have exactly one `PXDBIdentity` field as its surrogate primary key. Pair it with a separate natural-key field (a `PXDBString` with `IsKey = true`) that users see and enter.

**Important behaviors**

- The identity value is generated by the database, not by the application layer.
- Do not expose the identity column in the UI — set `Visibility = PXUIVisibility.Invisible` on the `PXUIField` attribute or omit `PXUIField` entirely.
- The identity column is not the same as the natural key. The natural key (e.g., `OrderNbr`) is what drives the URL, selector, and audit trail.

```csharp
#region OrderID
[PXDBIdentity]
[PXUIField(DisplayName = "Order ID", Visibility = PXUIVisibility.Invisible)]
public virtual int? OrderID { get; set; }
public abstract class orderID : PX.Data.BQL.BqlInt.Field<orderID> { }
#endregion
```

</Accordion>

<Accordion title="PXDBTimestamp — row version for optimistic concurrency">

Maps to SQL `TIMESTAMP` / `ROWVERSION`. The database updates this 8-byte binary value automatically whenever the row changes. The platform reads the timestamp on select and sends it back on update; if the values differ, another process has modified the row and the update is rejected with a concurrency error.

Add this field to every custom table that users will edit. It is the standard mechanism for preventing lost updates in a multi-user environment.

```csharp
#region tstamp
[PXDBTimestamp]
public virtual byte[] Tstamp { get; set; }
public abstract class tstamp : PX.Data.BQL.BqlByteArray.Field<tstamp> { }
#endregion
```

</Accordion>

## Unbound (non-persisted) field attributes

Unbound fields hold values only in memory during a request. They are never written to or read from the database, so they produce no SQL column. Use them for computed values, UI-only state, and intermediate calculations.

<Accordion title="PXString — unbound text">

Behaves like `PXDBString` for validation, input masking, and UI rendering, but the value is not stored. Common uses: display-only concatenations, search filter fields, transient status labels.

```csharp
#region DisplayName
[PXString(50, IsUnicode = true)]
[PXUIField(DisplayName = "Display Name", Enabled = false)]
public virtual string DisplayName { get; set; }
public abstract class displayName : PX.Data.BQL.BqlString.Field<displayName> { }
#endregion
```

</Accordion>

<Accordion title="PXInt — unbound 32-bit integer">

An in-memory integer field. Useful for computed counts, sort keys derived from other fields, or UI-only numeric state that should not be persisted.

```csharp
#region OpenLineCount
[PXInt]
[PXUIField(DisplayName = "Open Lines", Enabled = false)]
public virtual int? OpenLineCount { get; set; }
public abstract class openLineCount : PX.Data.BQL.BqlInt.Field<openLineCount> { }
#endregion
```

</Accordion>

<Accordion title="PXDecimal — unbound decimal number">

An in-memory decimal field. Use for running totals, margin percentages, or any derived monetary value that you compute in a graph event and display on screen.

```csharp
#region UnbilledAmount
[PXDecimal(2)]
[PXUIField(DisplayName = "Unbilled Amount", Enabled = false)]
public virtual decimal? UnbilledAmount { get; set; }
public abstract class unbilledAmount : PX.Data.BQL.BqlDecimal.Field<unbilledAmount> { }
#endregion
```

</Accordion>

<Accordion title="PXBool — unbound boolean">

An in-memory boolean flag. Use for transient selection checkboxes (e.g., a "selected" column in a processing screen grid) or any toggle that drives UI behavior without needing persistence.

```csharp
#region Selected
[PXBool]
[PXUIField(DisplayName = "Selected")]
public virtual bool? Selected { get; set; }
public abstract class selected : PX.Data.BQL.BqlBool.Field<selected> { }
#endregion
```

</Accordion>

## Quick reference

| Attribute | SQL type | Persisted | Typical use |
|---|---|---|---|
| `PXDBString(n)` | `NVARCHAR(n)` | ✅ | Text, codes, descriptions |
| `PXDBInt` | `INT` | ✅ | Foreign keys, whole-number values |
| `PXDBShort` | `SMALLINT` | ✅ | Small integers, sort orders |
| `PXDBLong` | `BIGINT` | ✅ | Large integers, external IDs |
| `PXDBDecimal(p)` | `DECIMAL(28,p)` | ✅ | Money, rates, percentages |
| `PXDBBool` | `BIT` | ✅ | On/off flags |
| `PXDBDate` | `DATETIME` (date) | ✅ | Business dates |
| `PXDBGuid` | `UNIQUEIDENTIFIER` | ✅ | UUIDs, file/user references |
| `PXDBIdentity` | `INT IDENTITY` | ✅ | Surrogate primary key |
| `PXDBTimestamp` | `ROWVERSION` | ✅ | Optimistic concurrency |
| `PXString(n)` | — | ❌ | Computed/display text |
| `PXInt` | — | ❌ | Computed/display integer |
| `PXDecimal(p)` | — | ❌ | Computed/display decimal |
| `PXBool` | — | ❌ | Transient UI flags |
